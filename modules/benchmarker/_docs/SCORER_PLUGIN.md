## Purpose
Guide for creating scorer plugins that evaluate benchmark sessions.
A scorer reads an immutable session YAML and produces scored verdicts stored in `scoring_runs`.
Each scorer owns its full workflow: it receives a session dict, renders any UI it needs into a Streamlit container, and writes its scores to the DB itself.

## Key files
- `scorers/base.py` — `ScorerPlugin` ABC and `ScoringResult` dataclass
- `scorers/prompt_renderer.py` — `RubricLoader`, `JudgePromptRenderer` (shared, rubric-based scorers only)
- `scoring_pipeline.py` — orchestrator; auto-discovers scorers, lists them, loads results from DB
- `benchmarker.py` — `ScoringRun` DB model (what gets persisted)

## Auto-discovery rule
Any file named `scorer_*.py` in `scorers/` is auto-discovered.
It must contain a class named exactly `ScorerPlugin` (or a class that inherits from `ScorerPlugin`).
No registration needed anywhere else.

## Minimal scorer template

```python
# scorers/scorer_myname.py
from typing import Dict
from modules.benchmarker.scorers.base import ScorerPlugin, ScoringResult

class ScorerPlugin(ScorerPlugin):   # class name must be ScorerPlugin
    id = "myname"                   # unique, snake_case, used as DB key
    name = "My Scorer"              # shown in UI

    def compute_score(self, session: Dict, config: Dict, container) -> None:
        """Render UI into container and compute scores."""
        session_path = config["session_path"]
        # render UI into container, compute scores, then:
        result = ScoringResult(
            scorer_id=self.id,
            session_path=session_path,
            scores={"my_metric": 0.85},
            overall=self._compute_overall({"my_metric": 0.85}),
            scorer_config={},
            source="my_source",
            notes=None,
            scored_at=self._now(),
            parse_errors=[],
            complete=True,
        )
        self._write_score(result)

    def is_available(self) -> bool:
        # return False if a required library or credential is missing
        return True
```

## Session dict structure

The `session` argument passed to `compute_score()` is a parsed YAML dict. Key paths:

```python
session["meta"]["scenario"]           # scenario name
session["meta"]["configuration"]      # { option_group: active_option, ... }
session["steps"]                      # list of step dicts
session["assertions"]                 # list of assertion result dicts
session["events"]                     # list of driver events

# Per step:
step["id"]                            # step id string
step["action"]                        # e.g. "user_send_message"
step["result"]["llm_response"]        # LLM answer (str, may be truncated)
step["result"]["injected_contexts"]   # list of { source, role, content_preview }
step.get("expected_response")          # optional reference answer (str or absent)
step["success"]                        # bool
```

## expected_response
Always optional. Never assume it exists.
```python
step.get("expected_response", "")   # safe access
```
If your scorer requires it, set `complete=False` with a parse error when absent.

## scores dict conventions

| Scorer type | Keys | Example |
|---|---|---|
| Rubric-based | rubric dimension ids | `{ "relevance": 4.0, "accuracy": 3.5 }` |
| Step-based | step ids | `{ "s1": 0.82, "s2": 0.79 }` |
| Single metric | one descriptive key | `{ "similarity": 0.81 }` |

- `overall` is computed automatically as mean of all non-None values (or can be set explicitly)
- Use consistent keys within a scorer — the comparer groups by scorer_id and aggregates across runs

## scorer_config conventions

`scorer_config` is stored in the DB and shown in the UI. Include everything needed to reproduce the score:

```python
scorer_config = {
    "rubric": "pedagogy",          # rubric name if used
    "model": "all-MiniLM-L6-v2",   # model if used
    "threshold": 0.75,             # any thresholds
    "library_version": "...",       # for reproducibility
}
```

## source values

| value | meaning |
|---|---|
| `"manual"` | human typed or imported from YAML |
| `"llm_paste"` | generated by external LLM, pasted by human |
| `"embedding"` | computed automatically from embeddings |

Add your own if none of the above fit — the field is a free string.

## Rubric usage (optional)

If your scorer uses rubric dimensions:

```python
from modules.benchmarker.scorers.prompt_renderer import RubricLoader, JudgePromptRenderer

loader = RubricLoader()                   # reads from rubrics/ dir
rubric = loader.load(config["rubric"])    # raises FileNotFoundError if missing
dims = [d["id"] for d in rubric["dimensions"]]
renderer = JudgePromptRenderer()
prompt = renderer.render(session, rubric) # includes reference answers if present
```

The scorer decides when and whether to show a rubric selector.
The benchmarker judge tab does not manage rubrics.

Rubric YAML format:
```yaml
name: My Rubric
dimensions:
  - id: relevance
    question: "Is the answer relevant?"
    guidance: |
      Score high if...
    scale: 5
```

## Do
- Name file `scorer_*.py`, class `ScorerPlugin`
- Render UI into `container`, not `st.*` directly
- Always return a `ScoringResult` via `self._write_score(result)` — only once per submit
- Populate `parse_errors` on partial failures, set `complete=False`
- Check `is_available()` is honest — the pipeline relies on it to skip gracefully
- Log with `log()` from `core.logging`
- Keep scorers stateless — no instance variables mutated during `compute_score()`
- Handle absent `expected_response` gracefully

## Don't
- Don't register manually anywhere (auto-discovery handles it)
- Don't import other scorer plugins
- Don't import Streamlit directly
- Don't modify the session dict or file
- Don't write to the DB directly — use `self._write_score()` which calls `ScoringPipeline.persist_result()`
- Don't call `_write_score()` more than once per user interaction
- Don't hardcode config values — use app JSON config via `get_section()`
- Don't hardcode prompt strings — use `get_prompt()` if prompts are involved
- Don't raise exceptions from `compute_score()` — always return a `ScoringResult`
