How to implement tests : pytest and pytest-bdd are used to write tests for the agents.

/tests/conftest.py is the entry point for pytest and pytest-bdd. It contains the fixtures and hooks that are used by the tests.
Steps are definied in /tests/step_defs/, features in /tests/features/
/tests/poc is a directory containing proof of concept tests.
